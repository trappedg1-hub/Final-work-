# Канон 2 — реалистичный стиль (эталон `images/raw_real/_canon2_hero.png`)

Снято замерами с эталонной генерации, по которой строим вторую версию игры.
Метрики считаются по области фигуры (зелёный фон исключён), кадр приведён к ширине 520 px.

## Правила генерации по канону

1. Эталон — только `_canon2_hero.png`. Каждый кадр дня 1 делается **одним проходом** от него.
2. В промпте блок STYLE LOCK: глянцевая кожа с широкими бликами, высокий контраст внутри кожи, фарфоровый холодный тон, платиновые волосы с резкими полосами отблеска, мягкие контуры без жёсткой обводки, фотореалистичное кресло.
3. Блок IDENTITY LOCK: то же лицо, те же волосы, **та же фигура** (большая грудь, полные бёдра, мягкая талия) — не стройнить.
4. Меняется только поза и одежда. Масштаб фигуры в кадре — как у эталона (≈97 % высоты), ступни внутри кадра.
5. После генерации — детерминированная цветокоррекция `tools/match_style.py` по статистике эталона (Lab mean/std), чтобы палитра набора совпала 1:1.
6. Никаких цепочек правок: один проход на кадр, дальше только цветокор и апскейл.

| контраст кожи | 0.112 | 0.108 | 0.110 | 0.111 | 0.106 |
| волосы RGB | 0.814/0.647/0.563 | 0.829/0.682/0.592 | 0.840/0.684/0.595 | 0.786/0.625/0.539 | 0.837/0.689/0.601 |
| доля бликов | 2.2 % | 1.3 % | 1.7 % | 0.9 % | 2.5 % |
| p99 кожи | 0.944 | 0.917 | 0.931 | 0.926 | 0.943 |

Тон кожи и контраст сходятся по всему набору; блики и платина — в пределах ±0.05 по каналам,
остаточная разница держится в пределах допуска восприятия.

Порог «доля бликов» — метрика на грани, она чувствительна: k=0.05 уже срезает много.
Оценивать глянец надёжнее по p99 (0.92–0.94 у набора при 0.944 у эталона).

## Палитра

- кожа: светлый фарфор `#DBC2B3` … тени `#B98B78`
- подтон теней: холодный розово-лиловый, не оранжевый
- волосы: `#D7A58B` в базе, блик почти белый
- худи: `#C9C9CB`, шорты: `#1C1C1E`, носки: `#F2F2F2`
